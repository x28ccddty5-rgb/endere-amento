AUDITORIA 03 — PONTO 03 — PACOTE DE IMPLEMENTAÇÃO LOCAL
Data do pacote: 31/10/2026

CONTEÚDO
Este ZIP contém somente os arquivos alterados/criados para o alinhamento final das permissões de leitura, apresentação da Pesquisa, filtros, exportação, Realtime e dependências backend. Não inclui o projeto completo, .env, node_modules ou dist.

REGRAS IMPLEMENTADAS
- stock.search libera leitura completa das 14 colunas de slots para os cinco perfis por padrão.
- stock.details.view permanece no catálogo como chave legada, sem efeito sobre apresentação, filtros, exportação ou leitura.
- Desktop e Mobile preservam as apresentações existentes.
- Filtros continuam locais sobre a base em memória.
- Excel/PDF da Pesquisa usam projeção operacional fixa de 12 campos, sem ID técnico, respeitando o resultado filtrado.
- Um canal slots-search-live é compartilhado nas áreas que consomem slots.
- divergencias-live exige divergences.view; resolução segue separada.
- Operações críticas bloqueiam quando a fotografia remota completa e o Realtime não estão prontos; RPCs atômicas seguem como validação final.
- Contexto de permissões é atualizado no evento TOKEN_REFRESHED. A autorização RLS Realtime fica em cache durante uma conexão e só é reavaliada com novo JWT/reconexão; revogação imediata de canal já conectado não é garantida.

ANTES DE COPIAR
1. Confirme que C:\Projetos\endere-amento corresponde ao snapshot enviado em 31/10/2026 e que não há alterações locais posteriores nesses mesmos arquivos.
2. Faça backup dos arquivos existentes listados em ARQUIVOS-E-SHA256.txt. O backup deve preservar os caminhos relativos.
3. Extraia o ZIP sobre a raiz do projeto, mantendo os caminhos de src/, tests/, docs/ e scripts/.
4. Não use git reset, git clean, checkout global ou restauração total do repositório.

VALIDAÇÃO NO WINDOWS (PROJETO LOCAL)
Execute na raiz C:\Projetos\endere-amento:

  npm run lint
  npm run build
  node --experimental-loader ./tests/ts-transpile-loader.mjs --test tests/*.test.mjs

A suíte foi executada neste pacote com 292 testes aprovados. O build não pôde ser confirmado no ambiente de montagem Linux porque o node_modules deste snapshot contém binários nativos Windows; valide npm run build no Windows local.
